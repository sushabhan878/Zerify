# Dashboard PRD (dashboard.md)

## Product

**Zerify -- Influencer Marketing Platform**

## Objective

The dashboard is the user's home after login. Its purpose is to help
users achieve their primary goal as quickly as possible.

-   **Influencers:** Discover brands, apply to campaigns, manage
    collaborations, and grow earnings.
-   **Brands:** Find creators, manage campaigns, and measure ROI.

------------------------------------------------------------------------

# Product Principles

1.  Action over analytics.
2.  Show the next best action immediately.
3.  Personalize recommendations using AI.
4.  Minimize friction to collaboration.
5.  Every dashboard element should increase successful collaborations.

------------------------------------------------------------------------
